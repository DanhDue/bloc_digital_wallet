# Task 7: Synchronize Shipped Native Plugins

Epic: [flutter_super_app_template](../epic/flutter_super_app_template/flutter_super_app_template.en.md)

## Requirement Analysis
Audit and synchronize the two production native plugins bundled in `packages/` with the upgraded native toolchain:
1. **`packages/logger_native_bridge`**:
   - **Android**: Ensure `build.gradle.kts` matches Kotlin 2.1.0 and AGP 8.13+.
   - **iOS**: Verify `Package.swift` SPM layout with FactoryKit 3.3.2 and `LoggerNativeBridgeContainer`.
   - Ensure Pigeon contracts are up to date and tests pass.
2. **`packages/native_security`**:
   - **Android**: Ensure FFI CMake / ndk-build and Kotlin bindings compile with Java 21 and NDK toolchain.
   - **iOS**: Verify `Package.swift` mixed C/C++/Swift SPM target configuration with FactoryKit 3.3.2 and `NativeSecurityContainer`. Verify `__attribute__((constructor))` anchor preserves FFI symbols under release dead-strip.
   - Ensure secure storage, biometrics, and SSL pinning bindings execute cleanly.

## Design Rationale
- **Infrastructure Integrity**: Shipped plugins must serve as reference implementations of the template's native architecture, maintaining identical standards to code generated by `pac_native_plugin`.
- **Applicable Skills**: `security-audit`, `architecture-audit`.

## Impact Analysis & Blast Radius
- **Target Files & Symbols**: `packages/logger_native_bridge/**`, `packages/native_security/**`.
- **Downstream Callers**: `lib/main.dart`, `packages/network/` (SSL pinning), `packages/logger/` (Native log forwarding).
- **Cross-Platform Bridges**: C FFI symbols (`getSslPin1`), Pigeon `LoggerHostApi`.
- **Target Test Coverage Threshold**: 100% test pass; 100% line coverage on security-sensitive methods.
