### 3.2 — Local DataSource (`packages/settings/lib/data/datasources/local/`)

> **Storage Strategy: Hybrid — `SharedPreferences` + File System (`path_provider`)**
>
> | Data | Storage | Lý do |
> |---|---|---|
> | `translation_version_<lang>` | `SharedPreferences` | Tiny string, truy cập nhanh theo key |
> | `available_languages` list | `SharedPreferences` (JSON-encoded) | Small list, không cần query phức tạp |
> | Offline pending sync queue | `SharedPreferences` | Tiny, cần persist qua app restart |
> | Translation JSON content (`en.json`, `vi.json`) | **File System** (`path_provider`) | Có thể lớn (10KB–500KB+); SP serialize toàn bộ XML mỗi lần write trên Android — không phù hợp |
>
> ❌ **Không dùng SQLite**: Translation JSON là blob text, không có quan hệ relational. SQL overhead không có lợi thế gì ở đây. `sqflite` trong `pubspec.lock` là transitive dep của package khác, không phải do `settings` dùng.
>
> ❌ **Không dùng Hive**: Project có Hive trong `pubspec.lock` nhưng **không có source nào đang dùng** (chỉ transitive dep). Hive cần TypeAdapter + codegen — thêm complexity không cần thiết khi data đã là `Map<String, dynamic>`.

- [ ] **[NEW]** `settings_local_datasource.dart`:
  - [ ] `getCachedTranslationVersion(String languageCode) → Future<String?>` — đọc từ `SharedPreferences` key `translation_version_<lang>`.
  - [ ] `saveCachedTranslationVersion(String languageCode, String version) → Future<void>` — ghi vào `SharedPreferences`.
  - [ ] `getCachedTranslationJson(String languageCode) → Future<Map<String, dynamic>?>` — đọc file từ `path_provider` → `getApplicationCacheDirectory()/translations/<lang>.json`.
  - [ ] `saveCachedTranslationJson(String languageCode, Map<String, dynamic> json) → Future<void>` — ghi atomic file (write to temp → rename).
  - [ ] `deleteCachedTranslation(String languageCode) → Future<void>` — xoá file JSON + xoá version key trong SP.
  - [ ] `getAllCachedLanguageCodes() → Future<List<String>>` — đọc từ SP key `cached_language_codes`.
  - [ ] `saveAvailableLanguages(List<AvailableLanguage> languages) → Future<void>` — JSON-encode vào SP key `available_languages`.
  - [ ] `getAvailableLanguages() → Future<List<AvailableLanguage>>` — JSON-decode từ SP.
  - [ ] `loadBundledFallback(String languageCode) → Future<Map<String, dynamic>>` — đọc từ `assets/locales/<lang>.i18n.json` qua `rootBundle.loadString()`.

## Phase 4: Extend `LocalizationManager`

> [!IMPORTANT]
> **HLD Section 2.2** chỉ định rõ `LocalizationManager` phải dùng **`BehaviorSubject`** (từ `rxdart`), không phải `StreamController.broadcast()`.
> **Lý do**: `BehaviorSubject` replay lại giá trị cuối cùng cho mọi subscriber mới (late subscriber). Nếu dùng `StreamController.broadcast()`, widget mount sau khi locale đã được set sẽ không nhận được giá trị → locale bị reset về mặc định.

- [ ] Thêm `rxdart` vào `packages/core/pubspec.yaml` nếu chưa có.
- [ ] Đổi `_localeController` từ `StreamController<Locale>.broadcast()` sang `BehaviorSubject<Locale>` (init với `currentLocale`).
- [ ] Add `registerOverrideCallback(Future<void> Function(Map<String, dynamic> json, Locale locale) callback)`.
- [ ] Add `applyDynamicTranslations(Map<String, dynamic> mergedJson)`:
  - Calls the registered override callback.
  - Emits updated locale on `_localeController`.
- [ ] Add `setLocaleFromCode(String languageCode)` — sets locale + emits on stream.
- [ ] **[MODIFY]** `lib/main.dart` — Register the override callback after `configureDependencies()`:

## Phase 5: SplashBloc — Bootstrap Orchestration

- [ ] **[NEW/MODIFY]** `SplashBloc` — locate or create in the appropriate package:
  - Event: `SplashStarted`
  - States: `SplashLoading`, `SplashComplete(nextRoute)`, `SplashError`
- [ ] Implement `_onStarted` handler flow:
  ```
  1. loadBundledFallback() → applyDynamicTranslations()   ← offline baseline, always first
  2. BootstrapUseCase.call()
      ├─ SUCCESS:
      │   ├─ [Pref] user_preferences.language → setLocaleFromCode()
      │   ├─ [Pref] if user_preferences == null → useDeviceLocale()
      │   ├─ [Stale] for each is_stale translation → FetchTranslationUseCase.call()
      │   ├─ [Purge] for each removed translation → deleteCachedTranslation()
      │   │         if active locale removed → load bundled 1.0.0 fallback
      │   ├─ [UI] saveAvailableLanguages(response.available_languages)
      │   └─ emit SplashComplete → navigate
      └─ FAILURE (network/timeout):
          └─ load last cached JSON from local storage → apply → emit SplashComplete
  ```
- [ ] Set max timeout of **5 seconds** for bootstrap network call. On timeout, proceed with cached data (never block user).

### 6.2 — ChecksumUtils

- [ ] **[NEW]** `packages/core/lib/utils/checksum_utils.dart`:
  - [ ] `computeSha256(Map<String, dynamic> json) → String` — canonical JSON string → SHA-256 hex digest.
- [ ] Unit tests: deterministic output, known hash values.

### 6.3 — Apply in `FetchTranslationUseCase`

- [ ] `mode == "full"` → discard local cache, save full JSON, update version.
- [ ] `mode == "delta"`:
  1. Load cached JSON.
  2. `DeepMergeUtils.deepMerge(cached, item.changes)`.
  3. `DeepMergeUtils.deleteKeys(merged, item.deletedKeys)`.
  4. `ChecksumUtils.computeSha256(merged)` — compare with `item.checksum`.
  5. **Mismatch** → delete cache → fetch `full_fetch_url` → repeat as Full mode.
  6. **Match** → save merged JSON + update version in local storage.
- [ ] Call `LocalizationManager.applyDynamicTranslations(mergedJson)` after saving.
